## ◈ PYTHON ENGINEERING WORKFLOW

### Step 1 — Data Cleaning

**Job Level Standardization**

Raw data contained inconsistent labels: `"Mid senior"`, `"Staff"`, `"Lead"`, `"Entry Level"`. Normalized into three clean categories:

```python
def clean_job_level(level):
    if pd.isna(level):
        return 'Unknown'
    level = level.lower()
    if 'junior' in level or 'entry' in level:
        return 'Junior'
    elif 'senior' in level or 'staff' in level or 'lead' in level:
        return 'Senior'
    return 'Mid'

df['job_level_clean'] = df['job_level'].apply(clean_job_level)
```

**Skill Normalization**

Collapsed variant spellings (`"NoSQL"`, `"SQL Server"`, `"Oracle"`) into canonical skill names for accurate demand counting:

```python
def normalize_skill(skill):
    if not isinstance(skill, str):
        return 'UNKNOWN'
    skill = skill.strip().upper()
    if 'SQL' in skill:    return 'SQL'
    if 'PYTHON' in skill: return 'PYTHON'
    if 'POWER BI' in skill or 'POWERBI' in skill: return 'POWER BI'
    if 'AZURE' in skill:  return 'AZURE'
    if 'AWS' in skill:    return 'AWS'
    return skill
```

## ◈ ADVANCED SQL ANALYTICS

### Hiring Stability Score

*Which companies hire steadily? Which ones spike unpredictably?*

```sql
WITH monthly_jobs AS (
    SELECT
        company,
        substr(first_seen, 1, 7) AS year_month,
        COUNT(*)                 AS jobs
    FROM postings
    GROUP BY company, year_month
),
stats AS (
    SELECT
        company,
        AVG(jobs)         AS avg_jobs,
        AVG(jobs * jobs)  AS avg_jobs_sq
    FROM monthly_jobs
    GROUP BY company
)
SELECT
    company,
    ROUND(avg_jobs, 2)                                              AS avg_monthly_jobs,
    ROUND(sqrt(avg_jobs_sq - avg_jobs * avg_jobs), 2)              AS hiring_volatility,
    ROUND(avg_jobs / NULLIF(sqrt(avg_jobs_sq - avg_jobs * avg_jobs), 0), 2)
                                                                   AS stability_score
FROM stats
ORDER BY stability_score DESC;
```

### Senior vs Junior Ratio Over Time

```sql
WITH job_levels AS (
    SELECT
        substr(first_seen, 1, 7) AS year_month,
        CASE
            WHEN lower("job level") LIKE '%junior%' OR lower("job level") LIKE '%entry%'
            THEN 'Junior'
            WHEN lower("job level") LIKE '%senior%' OR lower("job level") LIKE '%lead%'
            THEN 'Senior'
            ELSE 'Mid'
        END AS job_level
    FROM postings
)
SELECT
    year_month,
    SUM(CASE WHEN job_level = 'Senior' THEN 1 ELSE 0 END) AS senior_jobs,
    SUM(CASE WHEN job_level = 'Junior' THEN 1 ELSE 0 END) AS junior_jobs,
    ROUND(
        1.0 * SUM(CASE WHEN job_level = 'Senior' THEN 1 ELSE 0 END)
            / NULLIF(SUM(CASE WHEN job_level = 'Junior' THEN 1 ELSE 0 END), 0),
        2
    ) AS senior_to_junior_ratio
FROM job_levels
GROUP BY year_month
ORDER BY year_month;
```

### Company Market Share (Window Functions)

```sql
WITH monthly_totals AS (
    SELECT substr(first_seen, 1, 7) AS year_month, COUNT(*) AS total_jobs
    FROM postings GROUP BY year_month
),
company_monthly AS (
    SELECT company, substr(first_seen, 1, 7) AS year_month, COUNT(*) AS company_jobs
    FROM postings GROUP BY company, year_month
)
SELECT
    c.company,
    c.year_month,
    ROUND(100.0 * c.company_jobs / t.total_jobs, 2) AS market_share_percent
FROM company_monthly c
JOIN monthly_totals t ON c.year_month = t.year_month
ORDER BY market_share_percent DESC;
```

## ◈ CHALLENGES SOLVED

**Challenge 1: Multi-skill columns**  
Raw data packed 10+ skills into a single comma-separated string per row.  
→ Solved with `.explode()` transformations to generate row-level skill records.

**Challenge 2: Inconsistent job level labels**  
`"Mid senior"`, `"Staff Engineer"`, `"Lead"` — no standard format.  
→ Solved with CASE-based SQL logic + Python mapping functions.

**Challenge 3: Measuring hiring consistency**  
Simple job counts hide whether companies hire steadily or in erratic bursts.  
→ Solved with a custom **Stability Score** using standard deviation and average monthly hiring.
